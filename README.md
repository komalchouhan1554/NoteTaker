# NoteTaker
NoteTaker — Java Web Application

A full-stack Java web application for managing notes, built using Servlets, JSP, and Hibernate (with a relational database backend).

📖 Features

Create, Read, Update, Delete (CRUD) operations for notes

User login and session handling

Data persistence via Hibernate ORM

MVC-style architecture using Servlets + JSP

Basic UI using HTML/CSS / JSP views

Database support (e.g. MySQL)
